# Tetris

A Tetris game featuring a Java game engine and a JavaFX user interface, built with Gradle.

## Build and Run

### Requirements

- JDK 23 or later
- g++
- SDL3

### Clone the Repository

```bash
git clone https://github.com/kougen8610/Tetris-Foreign-Renderer.git
cd Tetris-Foreign-Renderer
```
### Run

```bash
bash run.sh
```
